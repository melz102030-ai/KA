# العلامة البصرية

`logo.jpeg` هو **المصدر الوحيد** لكل أيقونات التطبيق — 1024×1536، خلفيته `#FFFBF0`.
كل ملف في `apps/mobile/assets/` و `apps/mobile/public/` مشتقّ منه، فلا تعدّلها
يدوياً: عدّل المصدر وأعد التوليد.

> `logo.png` هو الشعار السابق، محفوظ للرجوع إليه فقط ولا يُشتقّ منه شيء.

## الاقتطاعان

قياسات بالبكسل داخل المصدر، مستخرجة بمسح البكسل. الفصل بين الرمز والكلمة عند
`y≈985`: عتبة الحبر عند 60 تجعل ظلّ الحقيبة يجسر الفجوة فتبدو الكتلتان واحدة،
وعند 90 فأعلى ينفصلان بثبات.

| الاسم    | x   | y   | العرض | الارتفاع | المحتوى             |
| -------- | --- | --- | ----- | -------- | ------------------- |
| `MARK`   | 231 | 163 | 561   | 823      | الحقيبة وحدها       |
| `LOCKUP` | 155 | 163 | 737   | 1162     | الحقيبة + «أكبادنا» |

`MARK` وحده يُستخدم في الأيقونات — الكلمة تصبح غير مقروءة تحت ~64 بكسل،
وأندرويد يقصّ الأيقونة دائرياً فيبترها.

## المشتقّات

`fit` = نسبة الضلع الأطول من المحتوى إلى ضلع اللوحة، والمحتوى متوسّط دائماً.

| الملف                                | المقاس   | الاقتطاع | fit  | الخلفية               |
| ------------------------------------ | -------- | -------- | ---- | --------------------- |
| `assets/icon.png`                    | 1024²    | MARK     | 0.72 | `#FFFBF0`             |
| `assets/android-icon-foreground.png` | 512²     | MARK     | 0.60 | شفافة                 |
| `assets/android-icon-background.png` | 512²     | —        | —    | `#FFFBF0`             |
| `assets/android-icon-monochrome.png` | 432²     | MARK     | 0.55 | ظلّية سوداء على شفافة |
| `assets/splash-icon.png`             | 1024²    | LOCKUP   | 0.80 | `#FFFBF0`             |
| `assets/favicon.png`                 | 512²     | MARK     | 0.80 | `#FFFBF0`             |
| `public/icon-192.png`                | 192²     | MARK     | 0.80 | `#FFFBF0`             |
| `public/icon-512.png`                | 512²     | MARK     | 0.80 | `#FFFBF0`             |
| `public/icon-maskable-512.png`       | 512²     | MARK     | 0.58 | `#FFFBF0`             |
| `public/apple-touch-icon.png`        | 180²     | MARK     | 0.80 | `#FFFBF0`             |
| `public/og.png`                      | 1200×630 | LOCKUP   | 0.86 | `#FFFBF0`             |

شاشة الدخول تستورد `assets/icon.png` مباشرةً، فتتبع المصدر بلا خطوة إضافية.

**لماذا `fit` أصغر في `maskable` و `android-icon-foreground`:** أندرويد يقصّ
الأيقونة بأشكال مختلفة (دائرة، مربع مستدير…) ولا يضمن ظهور إلا الـ 66% الداخلية،
وكذلك شارة `maskable` في PWA. القيم 0.58–0.60 تبقي الرمز كاملاً داخل تلك المنطقة
الآمنة مهما كان شكل القصّ.

**لماذا الخلفية كريمية في كل مكان:** الشعار مرسوم على `#FFFBF0`، فلو وُضع على
أبيض لظهر مربّع باهت حوله. لذلك `app.json` يضبط `backgroundColor` وخلفية شاشة
البدء وخلفية أيقونة أندرويد، و `manifest.json` يضبط `background_color`، على
القيمة نفسها. **عند تغيير الشعار يجب تغيير هذه المواضع الخمسة معه.**

## إعادة التوليد

عدّل المصدر ثم أعد قصّ الجدول أعلاه بأي أداة (Sharp، ImageMagick، Figma).
تحقّق من الاقتطاعين أولاً — إن تغيّر تكوين الشعار تغيّرت الإحداثيات.

```bash
# مثال بـ ImageMagick لأيقونة التطبيق
magick logo.jpeg -crop 561x823+231+163 +repage \
  -resize 737x737 -background '#FFFBF0' -gravity center -extent 1024x1024 \
  ../apps/mobile/assets/icon.png
```
